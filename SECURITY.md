# Security Policy

## Supported Versions

The following versions of the Web3 Security Auditor currently receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues. 

Instead, please use this repository's **Private Vulnerability Reporting** feature:

1. Navigate to the **Security** tab.
2. Select **Advisories** from the left sidebar.
3. Click the **Report a vulnerability** button.

We will acknowledge your report within 48 hours and provide regular status updates as we evaluate and patch the issue.
